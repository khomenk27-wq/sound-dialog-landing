# Школа Эффективной Коммуникации «ДИАЛОГ» (Движение «Звучим»)
## Интерактивный веб-тренажер метода «Живой Язык»

Интерактивное веб-приложение, объединяющее комикс-тренажер, лабораторию калибровки речи и презентацию образовательной экосистемы школы «Диалог».

---

### 🚀 Быстрый запуск

1. **Установка зависимостей** (уже выполнена):
   ```bash
   npm install
   ```

2. **Запуск в режиме разработки**:
   ```bash
   npm run dev
   ```
   Приложение откроется на `http://localhost:3000`.

3. **Сборка для продакшена**:
   ```bash
   npm run build
   ```
   Скомпилированные статические файлы сохраняются в директорию `dist/`.

---

### 📦 Реализованные модули

1. **Экран Hero (`Hero.tsx`):**
   - Провокационный заголовок о разрыве смыслов: «Мы говорим одно. Имеем в виду другое. А слышат третье».
   - Кнопка быстрого перехода в тренажер (~90 секунд).
   - Информационные бейджи метода (0% манипуляций, опора на реальность, без диагнозов).

2. **Интерактивный комикс-кейс «Коридор ожиданий» (`ComicSimulator.tsx`):**
   - Реалистичная панель переписки с аватаром и временной меткой (пятница, вечер).
   - Входящее сообщение: *«Понятно. Делай как знаешь.»*
   - Выбор из 3 реакций с разбором:
     - Обида / пассивная агрессия (достройка иллюзии +1).
     - Вина и спешное оправдание (достройка иллюзии +1).
     - Чистая фиксация 4 слов (очки ясности +1).
   - Интерактивный «Мостик Живого Языка» — демонстрация открытого вопроса без защиты.

3. **Лаборатория-сортировщик «Факт vs Интерпретация» (`FactQuiz.tsx`):**
   - 4 интерактивных кейса из рабочей и личной жизни.
   - 3D Flip-анимация карточек при проверке.
   - Детальный анализ: где физический факт (видеокамера), а где достройка ума.
   - Живой подсчет очков ясности.

4. **Манифест и культура школы (`Manifesto.tsx`):**
   - Три столпа Живого Языка: *Разделение слоев*, *Снятие защитной брони*, *Культура открытого исследования*.
   - Интерактивные вкладки форматов:
     - **Антинетворкинг** (контакт людей, а не статусных визиток).
     - **Чайные диалоги** (замедление темпа и 3 уровня слушания).
     - **Джемы и микрорейвы** (раскрепощение голоса и тела со «Звучим»).
   - Опора на академические источники (Бергер и Лукман, Маршалл Розенберг, Спиральная динамика).

5. **Конверсионный экран с калибровкой (`Conversion.tsx`):**
   - Динамический расчет процента калибровки реальности на основе ответов пользователя.
   - Персональный вердикт и рекомендации школы.
   - Бесшовный переход в Telegram-канал/бот сообщества.
   - Прямое скачивание официальной PDF-шпаргалки по Живому Языку.
   - QR-код для моментального сканирования со смартфона.

6. **Интерактивная шпаргалка 3×4 (`CheatSheetModal.tsx`):**
   - 4 Шага Живого Языка (Факт, Чувство, Потребность, Просьба).
   - 3 Уровня слушания (Слушаю себя, Слушаю собеседника, Слушаю поле).
   - 4 Ловушки ума (Чтение мыслей, Обобщения, Псевдочувства, Ультиматумы).
   - Скачивание всех оригинальных памяток в PDF.

7. **Шапка и Навигация (`Header.tsx`):**
   - Тонкий динамический прогресс-бар вверху страницы.
   - Переключатель темной и светлой темы оформления.
   - Живой индикатор счета (Ясность / Иллюзии).

### 🎨 Дизайн-система

- **Стиль:** Минималистичный нео-брутализм с мягкими тенями и чистой швейцарской сеткой.
- **Шрифты:** `Inter` (основной) + `JetBrains Mono` (код речи и факты).
- **Цвета:**
  - Тёмная тема: `#0F1115` (фон), `#181B22` (карточки), `#282D37` (бордеры).
  - Факт / Живой Язык: изумрудно-зеленый (`#10B981`).
  - Интерпретация / Ловушка: теплый янтарный (`#F59E0B`).
  - Действия / Кнопки: индиго (`#6366F1`).

npx vercel
