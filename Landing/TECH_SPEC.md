# Technical Specification & Deployment Guide

## 1. Технический стек
- **Bundler / Сборщик:** Vite (быстрая сборка, мгновенный HMR).
- **Фреймворк:** Vanilla JavaScript (ESModules) или React / Preact (по выбору агента для декларативного управления состоянием интерактива).
- **Стилизация:** Tailwind CSS (utility-first, без тяжелых сторонних библиотек).
- **Иконки:** Lucide Icons (через SVG).
- **Анимации:** CSS Transitions & Animations + минималистичный легкий JS для интерактивных переключений.
